# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub security advisories](https://github.com/imify-ai/imify-cli/security/advisories/new). Do not open a public issue.

Include the affected version (`imify --version`), the steps to reproduce, and the impact you observed. You receive an acknowledgement within five working days.

## Supported versions

Security fixes are released for the latest minor version.
